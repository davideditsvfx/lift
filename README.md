# gym

A minimal iPhone workout tracker with planned progression with a daily weigh-in, built as a Home Screen web app.

Open https://davideditsvfx.github.io/lift/ in Safari, tap Share → Add to Home Screen.
All data stays on the phone (Settings → Export Backup to keep a copy).

Publish changes: commit, bump `CACHE` in `sw.js`, then run `python3 scripts/publish.py`.
